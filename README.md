# FlowMinds://AI

Google Gemini API搭載のデスクトップ常駐型3Dキャラクター（デスクトップマスコット）アプリケーションです。

AIキャラクターがあなたのデスクトップに常駐し、会話・音声対話・画面認識・自律行動などを行います。

> Windows専用 / 無料（Gemini APIキーが必要 — 無料で取得可能）

---

## ダウンロード

[Releases](../../releases) ページから最新版の zip をダウンロードしてください。

### インストール方法

1. ダウンロードした zip を任意のフォルダに展開
2. `FlowMinds-AI.exe` をダブルクリックで起動
3. 初回起動時に SmartScreen の警告が出た場合は「詳細情報」→「実行」をクリック

> インストーラーは不要です。フォルダごと移動・削除するだけで OK。

---

## はじめ方

### 1. APIキーを取得（無料）

1. ブラウザで https://aistudio.google.com/apikey を開く
2. Googleアカウントでログイン
3. 「APIキーを作成」をクリック
4. 表示された `AIza...` で始まるキーをコピー

> APIキーは第三者に教えないでください。

### 2. APIキーを設定

1. アプリ右上の歯車アイコン（または `Ctrl+,`）で設定画面を開く
2. 「共通設定」→「API設定」でAPIキーを貼り付け
3. 「保存」をクリック

### 3. 会話開始

テキスト入力欄にメッセージを入力して `Enter` を押すと、AIキャラクターが応答します。

## 主な機能

- **自然な会話** — Gemini AIによる文脈理解と感情豊かな対話
- **音声対話** — 音声読み上げ・音声入力（無変換キーで即座に開始）
- **表情・モーション** — 感情に応じた自動変化、AIによる表情自動生成
- **記憶・人格成長** — 会話を記憶し、経験で性格が変化
- **インタラクション** — マウスで触ると反応、髪や服の物理演算
- **画面認識** — 作業内容を理解して話しかけてくれる
- **Web検索** — AIが自分でブラウザを操作して情報収集
- **自律動作** — スケジュール・画面監視・スリープ復帰など多彩なトリガーで自発的に行動
- **アプリ起動** — デスクトップアプリをAIに頼んで起動
- **プラグイン** — TRPG冒険、AITuber配信、オセロなど拡張可能
- **ナレッジベース** — Obsidian風のノート管理、AIとの情報共有
- **API使用量管理** — 使用量をセッション・日別・月別で確認

## フォルダ構成

```
FlowMinds-AI/
├── FlowMinds-AI.exe    # これをダブルクリックで起動
├── README.md           # 説明書
├── plugins/            # プラグイン（追加・編集可能）
├── library/            # ナレッジベース（ノート保存先）
└── runtime/            # アプリ本体（※触らないでください）
```

---

## データの保存場所

| データ | 場所 |
|--------|------|
| 設定・会話履歴・記憶 | `%APPDATA%\flowminds-ai\` |
| プラグイン | `plugins\` （アプリフォルダ内） |
| ノート | `library\` （アプリフォルダ内） |
| ログ | `%APPDATA%\flowminds-ai\logs\` |

---

## トラブルシューティング

| 問題 | 対処 |
|------|------|
| アプリが起動しない | SmartScreenの「詳細情報」→「実行」を試す |
| AIが応答しない | APIキーの設定・インターネット接続を確認 |
| 音声が出ない | 設定画面の音量・PCのスピーカーを確認 |
| PCが重い | 画面認識・自律動作をOFFにする |
